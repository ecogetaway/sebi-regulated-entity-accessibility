# Regulation

The primary-source layer. Everything else in this repository maps onto it.

- [`circular-chain.md`](circular-chain.md) — the six circulars, their dates and effects, the
  timeline as it actually stands, and the standards SEBI actually names
- [`obligations.md`](obligations.md) — all 24 obligations, each with its circular source and
  an observability class
- [`open-questions.md`](open-questions.md) — numbered questions that block or reword a
  criterion. **OQ-1 holds criterion S3.**

Cite these, not secondary coverage. Several widely-read guides carry the superseded 31 July
2026 deadline, list a cancelled milestone as live, and name standards versions SEBI never
wrote.

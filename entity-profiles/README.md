# Entity profiles

One structured assessment per Regulated Entity, scored against
[`../rubric/rubric.md`](../rubric/rubric.md). Use [`TEMPLATE.md`](TEMPLATE.md) to add one.

**Nothing lands here until it has been reproduced by hand.** A harness run is input to a
profile, not a profile. Rubric rule 7: every failure that reaches a published finding must
be reproduced manually and evidenced, because automated rules cover only a minority of WCAG
success criteria and some of the harness's heuristics produce false positives.

Profiles name real companies. Each one carries a right of reply, and each one ends with an
explicit statement of what it does not claim.
